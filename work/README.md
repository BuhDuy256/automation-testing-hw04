# HW05 Working Files

Use this directory for intermediate HW05 artifacts that are not ready for submission.

Suggested subdirectories:

- `plans/` — drafts and reviewed test-plan iterations
- `data/` — working CSV files and generated test data
- `raw-results/` — local run output before selection for submission
- `html-reports/` — exploratory report runs
- `resource-evidence/` — monitor captures and hardware evidence drafts
- `ai-analysis/` — raw AI analyses and review notes
- `drafts/` — report and proposal drafts

Only finalized, submission-ready artifacts should be copied into the root `out/` directory.

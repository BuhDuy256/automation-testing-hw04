# Official Load Visual-Evidence Instructions

No GUI screenshot is generated automatically by Codex.

For the assignment-required visual evidence, capture a real screenshot or video frame during the official run with all of the following visible at the same time:

1. The k6 execution window showing the official Load run and current progress.
2. Windows Task Manager or Resource Monitor showing CPU and memory activity.
3. The backend `node` process and the k6 process as separate processes.
4. The system clock or another visible timestamp.
5. Preferably the steady four-VU plateau rather than only startup or shutdown.

Do not substitute calibration screenshots or recreate the display after the run. If no image was captured during this invocation, report the visual evidence as missing.
